# Security

This tool is only for assets you own or are authorized to test. Read [AUTHORIZED_USE.md](AUTHORIZED_USE.md) before running it.

Use GitHub Issues to report a flaw in this repository. Do not paste real keys, the results database, or `DB_ENCRYPTION_KEY` / `DASHBOARD_TOKEN`.

If a key leaked in your own project, revoke it with the vendor and remove it from git history. In the issue, describe only the location and the key type.
